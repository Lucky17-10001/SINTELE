# REQUISITOS FUNCIONAIS E NÃO FUNCIONAIS
## (RF001-RF010 & RNF001-RNF027)
{RF001-O usuário deve cadastrar seu e-mail para fazer login

* RNF001-O sistema deve enviar um código de confirmação em até 20 segundos no e-mail inserido no cadastro

* RNF002-O sistema deve enviar o código de confirmação com prazo e expiração de 5 minutos 

* RNF003-O sistema deve deixar salvo o e-mail informado

{RF002-O sistema deve associar o usuário a um aluno existente de uma sala específica

* RNF004-O sistema deve reconhecer a sala e separar os estudantes por sala

* RNF005-O sistema deve reconhecer o nome inserido pelo aluno e colocá-lo na sala correta

{RF003-O sistema deve realocar o usuário à página inicial logo após o cadastro

* RNF006-O sistema deve realocar o usuário em até 5 segundos após o cadastro do e-mail

* RNF007-O sistema deve apresentar os botões de todas as áreas principais contidas no aplicativo(aba de chat, aba de tarefas, aba de atividades, etc.) e o Menu Hamburger (contendo a área de ajuda, feedback, como entrar em contato, etc.)

{RF004-O sistema deve fornecer um chat que permita a interação entre usuários

* RNF008-O sistema deve possibilitar ver quando algum usuário está online ou offline

* RNF009-O sistema deve possibilitar o uso de emojis

{RF005-O sistema deve fornecer um chat que permita a interação entre usuários e Inteligência Artificial

* RNF010-O tempo de resposta da I.A. deve ser no máximo 5 minutos

* RNF011-A I.A. deve buscar informações apenas em sites renomados

{RF006-O sistema deve possibilitar personalização no perfil do usuário

* RNF012-O sistema deve permitir a inserção de pronomes

* RNF013-O sistema deve possibilitar a mudança da foto de perfil

* RNF014-O sistema deve permitir a mudança de nome por meio de requisição em caso de mudança de gênero(transgênero)

* RNF015-O sistema deve possibilitar a seleção e alteração de áreas de dificuldade do aluno assim personalizando a experiência dele

{RF007-Área de contato disponível no Menu Hambúrguer

* RNF016-A área deverá conter informações de contato para suporte, como e-mail e número(s) de telefone(s)

* RNF017-O sistema deve permitir o redirecionamento do usuário ao clicar no e-mail ou número de telefone(Gmail/WhatsApp)

{RF008-Upload de vídeos

* RNF018-O sistema deve habilitar os usuários a disponibilizar vídeos na plataforma

* RNF019-O sistema deve utilizar inteligência artificial para revisar os vídeos compartilhados com a plataforma, a fim de evitar conteúdos impróprios na plataforma

* RNF020-O sistema deve encaminhar vídeos com possível conteúdo impróprio para os responsáveis do aplicativo para que sejam averiguados

* RNF021-O sistema deve conter um botão para denunciar possíveis vídeos com conteúdo inapropriado que não foram detectados pela I.A. 

{RF009-Upload de material para estudos

* RNF022-O sistema deve habilitar os usuários a disponibilizar resumos na plataforma

* RNF023-O sistema deve utilizar inteligência artificial para revisar os resumos compartilhados com a plataforma, a fim de evitar conteúdos impróprios na plataforma

* RNF024-O sistema deve encaminhar resumos com possível conteúdo impróprio para os responsáveis do aplicativo para que sejam averiguados

* RNF025-O sistema deve conter um botão para denunciar possíveis resumos com conteúdo inapropriado que não foram detectados pela I.A.

{RF010-Entrega de atividades

* RNF026-O sistema deve possibilitar que o professor envie atividades para os alunos com prazo

* RNF027-O sistema deve possibilitar que os alunos enviem as atividades para o professor
